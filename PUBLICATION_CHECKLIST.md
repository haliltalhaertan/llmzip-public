# Publication Checklist

This package is prepared for a separate public documentation repository or webpage. It has not been published as part of its preparation.

Before publication:

- Review the README, aggregate files, limitations, and evaluation proposal together.
- Keep the exploratory label and the previously seen questions / no clean holdout warning prominent.
- Preserve the narrow successful-reader-input-token definition beside the 23.2% figure.
- Decide whether to grant a documentation license and add the approved terms if desired.
- Create the public destination separately; do not change the original private repository's visibility or copy its history.
- Upload only the files listed in this package's manifest. Do not attach experimental data, prompts, answers, logs, or credentials.
- Verify the published page or repository anonymously and check that all included relative links resolve.
- Require a separate privacy, rights, and authorization review for any later code or data release.

The package checks establish its contents and arithmetic consistency. They do not independently validate the experiment.
